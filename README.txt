IMPORTANT CUSTOMISATION BEFORE SUBMISSION
1. Replace [Your Full Name] on every page with your name.
2. Replace [Your Matric ID] on every page with your matric number.
3. In about.html, add your actual previous school/college and qualification.
4. In portfolio.html, replace the achievement placeholders with real achievements.
5. In contact.html, add a public contact method only if you are comfortable sharing it.
6. Check every page and link in a browser before submitting.

HOW TO VIEW
Open index.html in a web browser. Keep all files in the same folder.

HOW TO HOST FOR FREE
You can use GitHub Pages:
1. Create or sign in to a GitHub account.
2. Create a new public repository.
3. Upload all files in this folder to the repository's main/root folder.
4. Open the repository Settings, then Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Select the main branch and /(root), then save.
7. Wait for GitHub Pages to publish the site. Copy the published URL into the assignment abstract.

The abstract.txt contains the 100-word website summary. Add your name, matric ID and published website URL to the abstract form supplied by your lecturer.

The contact page is informational and does not submit messages. Do not claim that it has a working contact form.
